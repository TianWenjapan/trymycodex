# administrator 网页说明

本目录包含一个纯静态网页，用于展示后端 `GET /logs` 接口返回的请求日志数据。

## 一、代码怎么编写

网页全部在单个文件 `index.html` 中实现，分为三部分：

### 1. HTML 骨架
- 页面标题
- 一个「刷新」按钮（`<button id="refresh">`）
- 一张表格（`<table>`），表头列为：ID、方法、路径、查询参数、请求体、时间

### 2. CSS 样式
- 表格加边框、隔行变色，便于阅读
- 请求体（body）列使用等宽字体，方便查看 JSON 内容

### 3. JavaScript 逻辑
- 用 `fetch('http://146.56.209.130:8001/logs')` 请求后端数据
- 后端返回形如 `{"logs": [{...}, ...]}` 的 JSON
- 遍历 `logs` 数组，每条记录生成一个 `<tr>`，各字段填入对应 `<td>`：
  - `id`、`method`、`path`、`query_params`、`body`、`created_at`
- 请求失败时在页面上显示错误提示
- 页面加载完成后自动拉取一次；点击「刷新」按钮重新拉取

## 二、网页怎么查看

前后端是分离的，需要分别启动：

1. **启动后端**（在项目根目录执行）：

```bash
python_vnev/bin/uvicorn main:app --host 0.0.0.0 --port 8001
```

2. **启动静态服务器**（在本 `administrator` 目录执行）：

```bash
python3 -m http.server 8080
```

3. **打开浏览器**访问：

```
http://146.56.209.130:8080
```

即可看到日志数据表格。后端需已加入 CORS 配置（见 `main.py`），否则浏览器会因跨域拦截而无法读取数据。
